## 📌 核心内容说明

### 量化交易基础

针对零基础读者，讲解量化交易的基本概念、核心流程（数据获取→策略编写→回测→实盘），以及常用的Python库（pandas用于数据处理、numpy用于数值计算、matplotlib用于可视化）的基础使用方法，为后续API接入和策略编写打下基础。

### iTick API 接入

这是本博客的核心内容，全程实战讲解iTick API的接入流程，包括：

- API 初始化：SDK安装、密钥配置、客户端创建；

- 行情数据获取：日K、周K、分时数据，以及多品种数据批量获取；

- 交易接口调用：委托下单、撤单、查询持仓、查询成交记录；

- 异常处理：网络超时、接口报错、权限不足等问题的排查与解决；

- 代码封装：将常用API调用封装为工具类，简化重复代码。

### 量化策略实战

结合iTick API获取的真实行情数据，编写基础量化策略，包括：

- 均线交叉策略：基于5日均线与20日均线交叉，实现买入卖出信号；

- MACD策略：利用MACD指标的金叉、死叉信号，结合成交量判断交易时机；

- 策略回测：使用历史数据验证策略有效性，计算收益率、最大回撤等关键指标；

- 策略优化：调整策略参数，提升策略盈利能力和稳定性。

## ⚠️ 注意事项

- API Key 属于敏感信息，请勿提交到GitHub等公开仓库，建议使用配置文件（如 `config.py`）管理，并将其加入 `.gitignore`；

- 实盘交易前，请务必进行充分的策略回测，熟悉iTick API的调用规则，避免因代码错误或策略漏洞导致损失；

- iTick API 有调用频率限制，具体限制请参考官方文档，避免频繁调用导致接口被封禁；

- 本博客内容仅用于学习交流，不构成任何投资建议，实盘交易需谨慎。
